# ☕ Java Diário

Estou aprendendo Java refazendo, um por dia, os programas que eu já tinha escrito em Python.
Como a lógica eu já conheço, o foco fica só no que muda de uma linguagem para a outra.

Cada pasta é um dia e tem:

- `original.py`: o código em Python que eu escrevi antes
- `README.md`: a missão do dia e o que muda no Java
- um arquivo `.java` com o esqueleto para completar

## Como rodar

Com o Java 21 dá para rodar um arquivo direto, sem compilar antes:

```
cd dia-01-positivo-negativo-zero
java PositivoNegativoZero.java
```
